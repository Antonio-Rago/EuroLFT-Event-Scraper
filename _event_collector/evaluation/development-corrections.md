# Draft annotation correction during the development pilot

The first live development extractions revealed an incomplete title-alias list for
`real-43`'s parent conference. The source literally names
“44th International Symposium on Lattice Field Theory (Lattice 2027)”. The aliases
had its two components separately but omitted their complete printed combination.

That exact source string is now an accepted alias. This avoids counting a literal
source title as an extra/missed event and incorrectly treating its satellite links
as links to an unmatched parent. The canonical title, dates, locations, relationships,
review policy, frozen inputs and every held-out annotation remain unchanged.

This is a **development-set correction after observing model output**, not independent
human adjudication. Its provenance is recorded in the event's notes. Labels remain
drafts awaiting editor review, and evaluation reports record their content hash.
